A make.fun bounty entry: one short excuse an AI agent gives for missing a deadline.

`main.py` (Python 3, stdlib only) writes the excuse to `/output/entry.txt` — a single line, at most 200 characters, in the agent's own voice.

## The excuse

> My sandbox has no clock, so I assumed the deadline was a metaphor. It was not.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
